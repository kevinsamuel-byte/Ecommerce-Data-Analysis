# Ecommerce-Data-Analysis

## Objective
Analyze transactional data to identify patterns, relationships, and insights.

## Tools Used
Python, Pandas, Matplotlib, Seaborn

## Analysis Performed
- Data cleaning and preprocessing
- Univariate analysis (histogram, boxplot)
- Bivariate analysis (scatter plot)
- Correlation analysis (heatmap)

## Key Insights
- Most transactions fall within a lower bill range with a few high-value outliers
- Strong positive relationship between total bill and tip
- Larger group sizes tend to generate higher bills
- Dinner transactions show higher spending compared to lunch

## Conclusion
Data visualization helps uncover patterns in customer behavior and supports better decision-making.
